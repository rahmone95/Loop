# Loop — استرداد الأدوية، استدامة الأثر

> Recover medicine. Sustain impact.

منصة سعودية لاسترداد الأدوية المنزلية المنتهية أو غير المستخدمة عبر شبكة من الصيدليات الشريكة. مبنية لـ **Rimthan Venture Building Hackathon — أبريل ٢٠٢٦**.

## نظرة عامة

- **١٥٠ مليون دولار** قيمة الأدوية الضائعة سنوياً في المملكة والخليج
- **٨٠٪** من أدوية المنازل تنتهي في القمامة
- **٩٤٪** من الأسر السعودية تدعم برنامج استرداد (دراسة محكّمة)
- **٠** برامج وطنية حالياً

Loop تربط بين الأسر، الصيدليات الشريكة، شركات الإتلاف المعتمدة، وشركات الأدوية كرعاة ضمن منظومة دائرية واحدة.

## ثلاث واجهات في تطبيق واحد

| المسار | الواجهة |
|---|---|
| `/` | تطبيق الأسرة (Splash → Home → Add Medicine → Drop-off → Impact) |
| `/pharmacy/dashboard` | بوابة الصيدلية الشريكة |
| `/admin/dashboard` | لوحة Loop التنفيذية (هيئة الغذاء والدواء + الرعاة) |

التبديل بينها من `/profile` ← "تبديل العرض (للجنة)".

## التقنية

- Next.js 14 (App Router, TypeScript, src dir)
- Tailwind CSS 3.4 + shadcn/ui (مخصّص بهوية Loop)
- framer-motion للحركات
- recharts للرسوم البيانية
- qrcode.react لرمز التسليم
- Anthropic SDK (Claude Sonnet 4.5) لتحليل صور الأدوية والرسائل التحفيزية

## التشغيل المحلي

```bash
npm install
npm run dev
```

افتح [http://localhost:3000](http://localhost:3000) — التطبيق mobile-first بعرض ٣٧٥px وRTL كاملاً.

### مفاتيح اختيارية

أنشئ `.env.local`:

```
ANTHROPIC_API_KEY=sk-ant-...
```

التطبيق يعمل بدونها بفضل بيانات وهمية احتياطية (mock fallbacks) في كل الـ API routes.

## API Routes

- `POST /api/analyze-medicine` — يستقبل صورة base64 ويرجع `{ name, expiryDate, status, confidence }`
- `POST /api/impact-message` — يولد رسالة تحفيزية مخصّصة من إحصائيات المستخدم

## المسار الذهبي للعرض (٦٠ ثانية)

1. `/` Splash ← `/onboarding` ← `/login` (دخول كضيف)
2. `/home` يعرض ٢٤٠ نقطة و٨ علب مستردة و١.٢ كجم أثر
3. `/add-medicine` ← ارفع صورة ← AI يعبّئ النموذج ← احفظ
4. `/pharmacies` ← اختر النهدي العليا ← "سلّم هنا"
5. `/dropoff/p_001` ← QR ← "محاكاة التأكيد" ← نجاح بـ confetti
6. `/profile` ← تبديل العرض ← الصيدلية ثم Loop التنفيذية

## نموذج الأعمال

- **المستخدم:** يدفع ٠، يكسب نقاط Loop تستبدل بكوبونات صيدليات
- **الصيدلية:** تستضيف صندوق Loop الذكي وتزيد ولاء العملاء
- **شركات الأدوية:** ترعى الصناديق + تحصل على بيانات مجمّعة + تقارير ESG
- **الجهات التنظيمية:** رؤية موحدة على معدلات الاسترداد والامتثال
